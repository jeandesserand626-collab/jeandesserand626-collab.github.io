# Security Incident

## Incident Overview

A suspicious email was reported by a user.
The email contained a link to an unknown website.

The purpose of this project is to document how a
cybersecurity professional could analyze and respond
to a potential security incident.

## Incident Type

Phishing / Suspicious Email

## Initial Indicators

- Unknown sender
- Suspicious link
- Unexpected email
- Request for sensitive information
- Possible credential theft

## Investigation Steps

1. Review the sender information.
2. Examine the suspicious link without opening it.
3. Check available email security logs.
4. Determine whether the user clicked the link.
5. Check for unusual account activity.
6. Document the evidence.
7. Report the incident to the security team.

## Containment

If the account appears compromised:

- Secure the account.
- Change the password.
- Enable Multi-Factor Authentication.
- End suspicious sessions.
- Block the malicious sender or domain.

## Evidence

Potential evidence may include:

- Email headers
- Sender information
- URLs
- Login records
- Security alerts
- System logs

## What I Learned

I learned how a suspicious email can become a potential
security incident and how important it is to identify,
document, investigate, and contain the threat.

## Security Recommendations

- Do not click suspicious links.
- Verify unexpected emails.
- Use Multi-Factor Authentication.
- Report suspicious messages.
- Keep systems and applications updated.
- Monitor unusual account activity.

## Conclusion

This project helped me understand the basic process of
analyzing and responding to a potential security incident.
