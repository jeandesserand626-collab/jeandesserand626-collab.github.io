# Password Security Lab

## Objective

The objective of this lab is to understand password security,
authentication, password hashing, and multi-factor authentication.

## Topics Covered

- Password strength
- Authentication
- Password hashing
- Multi-Factor Authentication (MFA)
- Password attacks
- Account security
- Security best practices

## What I Learned

I learned that strong passwords should be long, unique,
and difficult to guess.

I also learned that password hashing helps protect stored
passwords and that Multi-Factor Authentication adds an
additional layer of security.

## Password Security Risks

Common password security risks include:

- Weak passwords
- Reusing the same password
- Using personal information
- Sharing passwords
- Phishing
- Credential stuffing
- Brute-force attacks

## Security Best Practices

- Use long and unique passwords
- Never reuse passwords
- Use a password manager
- Enable Multi-Factor Authentication
- Never share passwords
- Avoid using personal information
- Be careful with suspicious links and emails
- Keep accounts and devices updated

## Authentication

Authentication is the process of verifying the identity
of a user before allowing access to a system or account.

Examples include:

- Passwords
- Security keys
- Authentication apps
- Biometrics
- Multi-Factor Authentication

## Conclusion

This lab helped me understand the importance of strong
passwords, secure authentication, password hashing,
and Multi-Factor Authentication in protecting accounts
and information.
